# EventHub

A marketplace platform connecting event clients with vendors.

## AI-assisted development

This repo uses [gstack](https://github.com/garrytan/gstack) for AI-assisted development. gstack auto-updates at the start of each Claude Code session.

On first clone, install it once globally:

```bash
git clone --depth 1 https://github.com/garrytan/gstack.git ~/.claude/skills/gstack
cd ~/.claude/skills/gstack && ./setup --team
```

Then run `claude` from the repo root — gstack loads automatically from there.
